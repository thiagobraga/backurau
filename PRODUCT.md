# Backurau

A desktop and service-backed file comparison, synchronization and backup app. The supplied numbered specifications in `/home/thiago/Downloads/backurau/` define behavior; `DESIGN.md` and the supplied page concepts define appearance.

Primary workflow: load a saved plan, compare aligned folder trees, review selected changes, run, inspect the report and restore retained versions. Four main views: Compare, Activity, Snapshots and Settings. Connections is a Settings tab. All displayed operational data comes from the real backend.

The user selected all four delivery phases and approved React/Vite, a shared Rust engine, rclone/rsync integration, OS credentials and a loopback token-authenticated service. Linux is the available validation host. Windows/macOS and authenticated remote providers require explicit external validation evidence.

Interface mode: Operate. Preserve the approved warm ivory/charcoal themes, compact geometry, red action accents and bird/wordmark assets. No invented demo files or success states.
